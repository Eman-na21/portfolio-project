# Graphic Designer Portfolio Website

A modern, responsive portfolio website built for a Graphic Designer to showcase design projects, branding work, visual assets, and creative services. Built using **React**, **JavaScript**, and **Tailwind CSS**.

## Features
* **Visual Gallery & Showcase:** Clean, high-impact layout for displaying creative artwork, banners, and design projects.
* **Modern UI/UX:** Built with utility-first Tailwind CSS for a sleek and responsive visual experience.
* **Interactive Components:** Smooth navigation, project filtering, and interactive UI elements.
* **Fully Responsive:** Optimized for crisp rendering across all screen sizes (mobile, tablet, desktop).

##  Tech Stack
* **Frontend:** React.js, JavaScript (ES6+), Tailwind CSS, HTML5, CSS3
* **Tools & Libraries:** Lucide Icons / React Icons, Node.js, npm
* **Version Control:** Git, GitHub
